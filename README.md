# 📅 大学课程表 · 教务系统课表导入工具

一个**纯前端、无需安装、数据不出本机**的课程表 Web 应用：把学校教务系统的课表（HTML 页面或 Excel 导出）一键解析成漂亮的周视图课表，支持周次/单双周、冲突检测、.ics 日历导出、打印。

> 所有数据保存在浏览器 localStorage 中，**不会上传到任何服务器**。

---

## 🚀 快速开始

**方式一（推荐）：双击打开**

直接双击 `index.html` 即可在浏览器中运行（无需安装任何软件）。

**方式二：本地服务器（可选）**

```bash
node server.mjs        # 默认 http://127.0.0.1:8080
node server.mjs 9000   # 自定义端口
```

**首次使用**：点击「载入示例」体验效果，或点击「导入课表」导入你自己的课表。

---

## 📥 如何导入教务系统课表

### 方式 A：粘贴课表 HTML（兼容性最好 ✅ 推荐）

1. 登录学校教务系统，打开「我的课表 / 课表查询 / 学期课表」页面；
2. 浏览器中按 **Ctrl+U**（或右键 → 查看网页源代码），**全选复制**；
   - 也可以只复制课表 `<table>` 所在片段；
3. 回到应用 → 「导入课表」→ 粘贴 → **解析预览** → 确认导入。

> 点击弹窗里的「填入示例 HTML」可以体验解析效果。

### 方式 B：上传 Excel（.xls / .xlsx）

部分教务系统支持导出 Excel 课表。应用会自动识别两种常见格式：

- **表格式**：星期 × 节次的二维表格（含合并单元格）；
- **列表式**：一行一条排课（含"课程名称/教师/周次/星期/节次/地点"列）。

### 方式 C：手动添加 / 恢复备份

- 「＋ 手动添加」逐条录入；
- 「导入 → 恢复备份」还原之前导出的 `.json`。

## ✨ 功能清单

| 功能 | 说明 |
|------|------|
| 智能解析 | 兼容正方 / 强智 / URP / 青果等常见教务系统表格：自动识别表头、节次列、rowspan/colspan 合并单元格 |
| 周次与单双周 | `1-16周`、`1-8,10-16周`、`2-16双周`、`1-15单周（单）` 等写法全部支持 |
| 周视图 | 按节次 × 星期网格展示，今天高亮、当前周高亮，卡片按课程配色 |
| 列表视图 | 按天分组的列表，适合快速浏览 |
| 冲突检测 | 自动标红时间重叠的课程（含周次重叠判断），工具栏显示冲突数 |
| 周导航 | ◀ ▶ 切换周次、一键回今天，支持键盘 ← → |
| 搜索 | 按课程名 / 教师 / 教室过滤 |
| 自定义节次时间 | 内置标准 12 节时间表，可逐节修改（支持不同学校的作息） |
| 学期设置 | 开学日期（第 1 周周一）、总周数、是否显示周末 |
| 导出 .ics | 导入手机/电脑日历：自动生成 RRULE（单双周用 INTERVAL=2，缺周用 EXDATE） |
| 备份 / 恢复 | 一键导出/导入 `.json` 完整备份 |
| 打印 | 打印当前周课表 |
| 隐私 | 纯本地运行，无任何数据上传 |

## ❓ 常见问题

**Q：粘贴 HTML 后提示"没有解析出课程"？**
确认复制的是课表页面源码（Ctrl+U 的原始 HTML），而不是网页上的文字。若页面是前端框架动态渲染（SPA），请在开发者工具（F12）的 Elements 面板里找到 `<table>` 元素 → 右键 → Copy → Copy outerHTML。

**Q：Excel 解析失败？**
试试把 Excel 另存为 `.xls`（97-2003 格式）再导入，或改用「粘贴 HTML」方式。

**Q：节次时间不对？**
不同学校作息不同，去「⚙ 设置」里逐节修改时间表即可，ICS 导出的时间会同步更新。

**Q：数据会丢失吗？**
数据存在浏览器 localStorage，清除浏览器数据会导致丢失。建议定期「导出 → .json 备份」。
